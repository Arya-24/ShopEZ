# 🛒 ShopEZ – E-Commerce Application

ShopEZ is a full-stack e-commerce web application designed to provide a simple and convenient online shopping experience. The platform allows customers to browse products, manage their cart, place orders, and view their profiles, while administrators can manage products, orders, and store information through an admin dashboard.

## 🚀 Features

### 👤 User Features

* User registration and login
* Browse products by category
* View product details
* Add products to cart
* Manage cart items and quantities
* Place orders
* View profile and order information

### 🛠️ Admin Features

* Secure admin authentication
* Add, update, and delete products
* Manage product categories and details
* View and manage customer orders
* Admin dashboard for store management

## 💻 Technologies Used

### Frontend

* HTML
* CSS
* JavaScript
* React.js

### Backend

* Node.js
* Express.js

### Database

* MongoDB


## 🎯 Project Objective

The objective of ShopEZ is to develop a functional e-commerce platform that demonstrates the implementation of modern web development technologies, including frontend development, REST APIs, database management, authentication, and administrative operations.
